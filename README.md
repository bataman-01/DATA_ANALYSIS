Module 1 — Data Collection and Cleaning
Load the dataset using Pandas, identify missing values and duplicate transactions, handle cancellations, and create a cleaned dataset.

Module 2 — Exploratory Data Analysis (EDA)
Analyze monthly revenue, top-selling products, purchase frequency, and revenue by country. Generate graphs using Matplotlib and Seaborn.

Module 3 — Customer Segmentation
Apply RFM analysis (Recency, Frequency, Monetary value) and K-Means clustering to identify loyal, occasional, high-value, and inactive customers.

Module 4 — Predictive Machine Learning
Train Logistic Regression and Random Forest models to predict whether a customer will make another purchase within the next 30 days. Use chronological training and testing periods to avoid data leakage.

Module 5 — Interactive Dashboard
Build a Streamlit dashboard with sales trends, customer segments, predicted return-purchase probabilities, and business recommendations.
